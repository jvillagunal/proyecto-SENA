README de integración del frontend real

Esta carpeta contiene una copia del frontend real del proyecto GrigoriPerelmánApp integrada como evidencia para la entrega GA7-220501096-AA4-EV03.

Estructura incluida:
- *.html (páginas: index, login, register, dashboard, history, new-problem, profile, solution)
- css/styles.css
- js/*.js (auth.js, utils.js, dashboard.js, history.js, problem.js, profile.js, solutions.js)
- assets/imagenes/

Instrucciones rápidas:
1. Abrir `index.html` en un navegador moderno.
2. Para simular usuarios, la app usa `localStorage` y `sessionStorage`.
3. Las funcionalidades de exportar/ocr/compartir están simuladas en el frontend.
