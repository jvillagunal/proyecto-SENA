Solución para: \(x^2 - 5x + 6 = 0\)

Paso 1: Identificar coeficientes

La ecuación cuadrática \(ax^2 + bx + c = 0\) tiene coeficientes:

\(a = 1\), \(b = -5\), \(c = 6\)

Paso 2: Aplicar fórmula cuadrática

\[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\]

Paso 3: Calcular discriminante

\(\Delta = (-5)^2 - 4(1)(6) = 25 - 24 = 1\)

Paso 4: Obtener soluciones

\(x_1 = \frac{5 + 1}{2} = 3\), \(x_2 = \frac{5 - 1}{2} = 2\)
