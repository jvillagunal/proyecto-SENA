Contenido:
- Proyecto React minimal (Vite) con navegación entre vistas.
- Documentos de soporte (diagramas, historias de usuario, checklist).

Instrucciones rápidas:
1. Abrir terminal en esta carpeta.
2. Ejecutar `npm install` para instalar dependencias.
3. Ejecutar `npm run dev` para iniciar servidor de desarrollo.
